# 商用友好大模型教师离线蒸馏与造数方案

## 1. 为什么要做“教师离线蒸馏”？

AetherTTS 面临两个现实约束：
1. **小模型容量约束（~10M–15M）**：小模型如果直接从嘈杂、多口音、多说话人的野生数据（in-the-wild）里学，既要学音色对齐、又要抗噪、又要学韵律，结果往往是“发音含糊、机械味重”。
2. **中英混读单音色数据稀缺**：开源且商用友好的语料中，缺乏同一个高质量说话人同时覆盖“标准中文 + 标准英文 + 自然中英混读”的录音棚数据。

借鉴 2026 年 **Paradee**（将 Kokoro-82M 单音色蒸馏到 8M，UTMOS 仅掉 0.11，单核 CPU 提速至 25× 实时）的实践证明：**让大模型教师离线产出高度一致、干净的单音色双语数据，再对小模型做“两段式监督 + 对抗训练”，是小模型跨过“玩具→产品”门槛性价比最高的路径。**

---

## 2. 商用合规注意事项（红线）

在执行教师离线造数前，必须守住以下三条合规底线：
1. **教师模型协议合规**：仅选用 **Apache 2.0 / MIT** 许可的开源教师模型（如 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)、[Fun-CosyVoice 2/3](https://github.com/QwenAudio/CosyVoice)、[Kokoro-82M](https://github.com/hexgrad/kokoro)）。
2. **参考声纹来源合规（最关键！）**：**严禁克隆未经授权的真人声纹或非商用数据集音色（如标贝 BZNSYP）用于商用上线**。合规来源包括：
   - 团队内部/签约配音员自录的 1–5 分钟高清干声（版权完全自有）；
   - 开源商用许可语料中筛选的单个干净说话人（如 Apache 2.0 的 `AISHELL-3` 或 CC BY 4.0 的 `Hi-Fi TTS`）；
   - 使用教师模型的 Voice Design（文本描述捏音色，无真实对应个人声纹）。
3. **文本语料合规**：造数所用的 Prompt 文本应来自公开商用文本语料或大模型合规生成的对话/指令文本，不爬取受版权保护的小说/剧本。

## 3. 离线造数流程（严控目标：清洗后 20–25 小时黄金单音色双语语料）

```text
[Step 1: 构建高覆盖 Prompt 文本池（宁精勿滥）]
  • 原始生成约 24,000 ~ 28,000 句，经四重过滤后精确留存 ~20,000 句（约 20–25 小时）
  • 配比建议：
      - 60% 中文口语/助手问答/播报（~12–14h，强制覆盖常见多音字、三声连读、数字/日期/金额/时间）
      - 25% 英文口语/日常指令/科普短句（~5–6h，覆盖 CMUdict 高频音素组合与连读）
      - 15% 中英混读（~3–5h，如科技词汇、APP 名称、日常英文单词嵌入中文句式）
  • 句长分布：短句（3–8 字，20%，专门训练低延迟首包）、中句（10–25 字，60%）、长句（25–45 字，20%）
       │
       ▼
[Step 2: 教师离线批量合成]
  • 主力教师：Qwen3-TTS-1.7B / Fun-CosyVoice 3（固定同一合规参考声纹 + 固定采样温度避免音色漂移）
  • 统一输出 24 kHz 单声道 WAV，同时保留原始文本与 TN 规范化文本
       │
       ▼
[Step 3: 自动化四重质检漏斗（宁缺毋滥，预期淘汰 15%–25%）]
  1. 时长与静音检：过滤过短（<0.8s）/过长（>12s）/异常拖音、截断尾音样本
  2. ASR 回译校验：用 Whisper-large-v3 / SenseVoice 转写，严格丢弃 CER > 0（或错读多音字/漏读英文词）的样本
     （注意：Qwen3-TTS 在编号/地址/数字串上偶有错读，ASR 校验尤为关键！）
  3. 声纹一致性校验：用 WeSpeaker / CAM++ 提取说话人余弦相似度，剔除相似度低于阈值（如 < 0.78）的漂移样本
  4. 听感质检：用 UTMOS / DNSMOS 过滤掉底噪、电流声、吐字不清的样本（仅留 Top 80%）
       │
       ▼
[Step 4: 伪标签提取（供小模型高效监督）]
  • 音素序列：由 AetherTTS 统一中英前端生成
  • 强制对齐时长（Duration）：MFA (Montreal Forced Aligner) 提取精确帧级时长
  • 连续基频与能量（F0 / Energy）：RMVPE / Harvest 提取，统一插值并做说话人均值方差统计
```

## 4. 两类蒸馏训练路径（实验阶段按需选择）

### 路径 A：音频级数据蒸馏（推荐主力，严控单卡 1 天内收敛）
当教师模型与学生模型架构不同时（例如 AR Codec 教师 → 单步流式学生），**无需先在几百小时多说话人语料上耗费算力预训练**，直接基于上述 20–25 小时极纯净单音色双语黄金集训练：
1. **Stage 1 热身**：全网监督训练（Duration / F0 / Energy + 多分辨率 STFT 重建），快速收敛对齐与发音；
2. **Stage 2 对抗精调**：开启 **MPD + MRD + WavLM SLM 对抗损失**；
3. **关键技巧（防“嗡嗡声”）**：进入对抗微调阶段后，将梅尔/频谱重建损失权重从常规的 `45` 逐步下调至 `3–10`，让判别器充分塑形 2–8 kHz 的自然气声与齿音质感。

### 路径 B：白盒特征级半拆蒸馏（Paradee 范式，适用于同源教师，如先训一个 40M 非流式强教师 → 蒸馏 10M 流式学生）
如果你想把 AetherTTS 自身的流式版本做到极致，还可以**先用相同的数据训一个“非流式全双向大模型教师（如 30M–50M，全句上下文）”**，再对 **10M 流式小模型**做白盒蒸馏：
1. 用非流式大教师给训练集跑一遍前向，离线保存每一句的 **Duration、F0、Energy、中间声学隐特征及高质量波形**；
2. **解耦训练两半**（不需要难收敛的端到端对齐学习）：
   - **流式文本/韵律侧（~4.5M）**：在严格右前瞻 $L$ 约束下，直接拟合非流式大教师的 `log-duration`、`F0`、`Energy` 与中间特征——相当于把“全句视角学到的完美韵律”蒸馏进“仅看 $L$ 步前瞻的流式学生”！
   - **瘦身因果解码器（~4M）**：直接吃教师的精确特征，先做频谱重建热身、再做高权重对抗训练还原教师波形；
3. 拼接两半做短周期联合微调（消除暴露偏差）+ INT8 校准量化。

> **核心价值**：路径 A 解决“缺少单人中英混读精品录音”的数据瓶颈；路径 B 解决“有限右前瞻流式小模型韵律不如全句大模型”的建模瓶颈。两者在 Phase 2 可以完美叠加使用。
